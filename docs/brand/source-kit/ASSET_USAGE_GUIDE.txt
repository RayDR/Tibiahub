TibiaHub Brand Kit v2

Recommended usage
=================

Can the current resources be used in the primary navbar?
- Yes, the current PNG assets are usable immediately for prototype and production if needed.
- For the smallest navbar icons and any UI that must stay crisp on every DPI/theme, SVG redraws are still recommended later.
- Use PNGs now as the approved visual reference set; convert/redraw to SVG afterward for the final UI system.
