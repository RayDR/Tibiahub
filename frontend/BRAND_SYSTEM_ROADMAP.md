# TibiaHub Brand System Roadmap

This roadmap is intentionally implementation-first.

## Milestone A — Foundation enforcement

Deliverables:

- brand authority and decisions,
- automated brand validation,
- package/CI integration,
- asset registry,
- migration checklist.

Exit criteria: a contributor can discover and run the brand checks without reading project history.

## Milestone B — Canonical component gallery

Deliverables:

- one route/page that renders canonical buttons, inputs, tabs, badges, cards, states, tables, overlays, headers, sprite treatments, domain icons, and responsive examples,
- default theme shown as the canonical identity,
- all skins testable against identical markup.

Exit criteria: new UI can be assembled by copying supported component compositions rather than inventing styles.

## Milestone C — Cyclopedia normalization

Deliverables:

- compact sprite entity pattern,
- combat entity pattern,
- location/zone pattern,
- standardized search/filter tabs,
- standardized detail hierarchy,
- standardized map/coordinate treatment.

Exit criteria: Creatures, Bosses, Loot, Quests, Hunt Zones, and NPCs visibly share the same product language.

## Milestone D — Product-wide migration

Deliverables:

- Home,
- Planner/maps,
- Guild,
- Events/Raffles,
- Auth/Profile,
- Admin.

Exit criteria: no product area behaves as a separate visual brand.

## Milestone E — Official asset/manual package

Deliverables:

- canonical logo set,
- icon/domain asset set,
- social/OG assets,
- backgrounds/patterns,
- generated brand manual and implementation manual.

Exit criteria: the manual documents the production system and uses the same source assets/tokens rather than maintaining a disconnected visual mockup.
